# Добро пожаловать в интернет-магазин мебели

## Возможности нашего сайта

На нашем ресурсе вы можете:

* **Ознакомиться с ассортиментом** представленных товаров
* **Использовать систему фильтрации** для поиска нужных товаров
* **Оформить заказ** на любой ассортимент мебели
* **Подписаться** на новости и обновления магазина

## О проекте

Наш интернет-магазин включает **три основные страницы**, которые обеспечивают полный цикл выбора и покупки мебели. Удобная навигация и продуманный интерфейс помогут вам быстро найти и заказать желаемые товары.

## Технические особенности

В разработке проекта использованы следующие технологии:

* **HTML** — базовая структура веб-страниц
* **CSS/SASS** — каскадные таблицы стилей
* **БЭМ** — методология разработки
* **Git** — система контроля версий
